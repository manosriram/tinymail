tinymail - lightweight email client

Update and add this yaml to `$HOME/tinymail.yml`
```yml
imap_host: IMAP_HOST
imap_port: 993
smtp_host: SMTP_HOST
smtp_port: 465
username: email
sent_folder: Sent
drafts_folder: Drafts
```
